Whole Wheat House & Bakery - website
====================================
Files
  index.html      page structure
  css/style.css   all styling (colors are variables at the top)
  js/main.js      Arabic/English text, menu items + prices, mobile menu
  assets/         logo.jpg, hero.jpg, pastries.jpg, bread.jpg

How to publish
  Upload the whole folder to your hosting (keep the folder structure).
  index.html must be in the root of the site.

Photos from wholewheatbakery.ae
  The product cards (bread, maamoul, pantry) and the terrace banner load
  https://wholewheatbakery.ae/bread.webp, maamoul.webp, pantry.webp, terrace.jpg
  directly from your current site. If they are missing, the page falls back to
  local images/colors. To host them yourself: download the files, put them in
  assets/, and change the URLs in index.html and css/style.css.

Edit content
  Text (Arabic + English): js/main.js -> TEXT
  Menu items and prices:   js/main.js -> MENU
